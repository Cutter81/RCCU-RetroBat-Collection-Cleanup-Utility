2. SECTION 20 — PAUSE / START / STOP / START OVER

Replace the existing START OVER subsection with:

START OVER
------------
START OVER is unavailable while RCCU is actively processing.

It becomes available only after a normal finish or after STOP has completely
unwound the maintenance loop.

When selected, START OVER closes the current RCCU window and launches a fresh
PowerShell RCCU process. The new process opens at the root-directory selection
window so another directory/run can be selected cleanly.

The current run is not resumed and the current processing window is not reused.

30. VERSION 4.31 CHANGE NOTE
============================

Version 4.31 documents the current v4.31 implementation, including the
START OVER lifecycle behavior and the preceding v4.30 path-handling
correction.

Version 4.30 included a narrow Stage 7 media/path correction for malformed or
unusual filenames that could cause GetFileNameWithoutExtension to throw an
Illegal characters in path exception during media processing.

Version 4.31 adds/finalizes the START OVER behavior:

- START OVER is disabled while maintenance is running.
- STOP must fully unwind the maintenance loop before START OVER becomes
  available.
- A normally completed run also enables START OVER.
- START OVER launches a fresh PowerShell RCCU process using the current script
  and then closes the finished/stopped RCCU window.
- The fresh process returns to the root-directory selection window rather than
  attempting to reuse the current run state.
